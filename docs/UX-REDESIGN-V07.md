# PixelWeave · UI/UX 效率改造 v0.7

> 2026-10-25 · 目标：让浏览动画、拆帧研究和像素创作都变成少滚动、少跳转、少重复操作的工作流。本次不引入任何图片生成，不改变药瓶本体像素、动画或来源数据。

## 现状问题（改造前）

1. **参考库是长网页，不是研究工具**：大标题、简介、巨大的帧画布、纵向叠放的帧索引/笔记/来源，使观看、选择和记录无法同时发生。
2. **功能按数据模块堆叠，而非任务顺序**：素材筛选、观看、逐帧、记笔记实际是同一项任务，却在界面不同高度。
3. **工作站把辅助流程和主绘制区平级展示**：LLM 创作描述面板在时间轴下常驻，拉长页面并稀释当前目标。
4. **空间不经济**：参考库仅十件条目，但两栏大卡片和一长串声明占用过多垂直空间。
5. **返回成本高**：缺快捷键、最近一次选中记录、可隐藏边栏，很难把浏览器当常用美术工具。

## 新布局与信息层级

### 参考库：三栏工作台

| 左（发现） | 中（观察） | 右（研究） |
|---|---|---|
| 搜索、分类、排序、筛选 | 当前作品 + 动画播放器 | 观察问题 + 本地笔记 |
| 紧凑源站小预览 + 署名 | 时间轴 + 速度 + 帧状态 | 作者 / 授权切换标签 |
| 资料条目滚动 | 洋葱皮 / 差分 / 透明网格 | 合法本地精灵表导入折叠 |

三栏的视觉权重为 **220–240px / 灵活主体 / 260–300px**；中间区域尽量保持实际动画视觉焦点，左右两栏彼此独立滚动。

桌面首屏应尽量容纳来源列表、主画面、播放控件和帧缩略图；不为了完全无滚动而把按钮和中文压到无法阅读。

### 工作站：画布优先

- 首页宣传 Hero 控制高度，不再占据整个首屏；唯一获准的药瓶资产不重复强调 11 次。
- Studio 采用紧凑顶部工具栏（立即跳转图层解剖 / 按需打开 LLM 创作）。
- 原素材、画布、属性检查器的三栏操作逻辑保留；播放工具与帧缩略图收紧间距但不改变数据格式。
- 大段 LLM Prompt/导入功能放进默认收起的 details：需要时随时展开，功能并未删除。
- 原先优秀的斜向图层展开预览不动，加入快速定位按钮而不是删掉它。

### 响应式策略

- 桌面约 ≥1210px：完整三栏。
- 小笔记本约 961–1210px：缩窄两侧栏，保住中央。
- 平板约 701–960px：左侧列表 + 播放器，研究面板排在下方，侧栏可独立折叠。
- 手机 ≤700px：纵向布局，参考列表在顶部收纳进限高列表，播放器优先大字、按钮至少约 32–40px；交互标签仍保留，不把内容粗暴缩小。

## 实际节省的操作

**研究一个新火焰素材**：左栏点选 → 中栏播放/按箭头逐帧 → 右栏对照问题、写笔记，不再上下滚动寻找各区。

**反复复习**：页面自动记住上次查看的作品、侧栏状态、研究标签页，收藏和笔记通过 localStorage 保存在同一浏览器中。

**深度拆解**：合法下载 PNG → 在右侧展开「本地精灵表拆帧」→ 输入行列 → 播放/帧差分析。该操作从未上传文件。

**学习再创作**：全站顶部从参考库直接跳 Studio；Studio 顶部一键跳到图层解剖或打开 LLM 创作面板。

## 键盘与可访问性

- / 搜索；← → 逐帧；Space 播放/暂停；F 收藏；Esc 关闭快捷键说明。
- 若焦点在 input / textarea / select / 可编辑内容中，不截获按键，不破坏文本编辑。
- 左右栏切换按钮同步 aria-pressed；右侧研究选项使用 tablist、tab、tabpanel 关联，内容可显隐。
- CSS 考虑无障碍 focus-visible；并保留原作者作品的来源信息和许可，不挪为项目素材。
