# PixelWeave Roadmap

## v0.2：Web Gallery + Studio（当前）
- [x] 双模式网站与移动端布局。
- [x] 药瓶、蓝药瓶、提灯、结晶四件循环像素动画。
- [x] 编辑资产、时间轴、动画控制、像素画笔。
- [x] PNG、Spritesheet、JSON、WebM 基础导出。
- [x] LLM Prompt → JSON 像素资产手动导入。
- [x] 静态部署工作流与 Node.js 本地开发服务器。

## v0.3：LLM 原生资产流水线（P0）
- [ ] 版本化 Pixel DSL 数据规范：轮廓、色板、材质、运动部件。
- [ ] 本地 API Proxy，支持 Ollama 与 OpenAI-compatible API，保护密钥。
- [ ] 生成失败自动反馈与重试、局部修复。
- [ ] 逐帧连续性、色彩统一、孤立像素、帧间闪烁的质量指标。
- [ ] 多轮生成：剪影 → 色板 → 细节 → 动画 → 评估。

## v0.4：成熟精灵工作站（P1）
- [ ] 画笔图层、选择、撤销重做、调色板、项目管理。
- [ ] 手工编辑和 LLM 编辑共同作用于相同资产图层。
- [ ] GIF / APNG / 自选帧率与尺寸导出。

## v0.5：场景与动态壁纸（P1）
- [ ] 背景、前景、景深分层、像素视差。
- [ ] 粒子/风雨/光效确定性周期、音效与镜头。
- [ ] 多资产组合与场景时间轴、无缝循环自动检测。

## v1.0：作品生态（P2）
- [ ] Lively Wallpaper HTML 导出与视频壁纸。
- [ ] 作品合集与公开展示。
- [ ] LLM 模型适配、生成质量与成本基准测试。
