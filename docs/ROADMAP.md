# PixelWeave 版本路线

## 已交付 v0.3 — LLM-native layered pixel assets
- [x] 统一分层 JSON 数据格式与严格验证。
- [x] 七层十帧的药水样品展示（真实图层可编辑，非模型声称产出）。
- [x] 人类能够查看和编辑图层、每帧独立像素、位置、透明度、顺序。
- [x] 复制/删除动画帧，撤销/重做，浏览器本地持久化。
- [x] 分层 JSON 直接导入/导出，兼容旧资产。
- [x] Ollama / OpenAI-compatible 文本 LLM 本地代理。
- [x] Director → Layered Pixel Generation → JSON Repair 结构化流水线。
- [x] 基础帧间变化、像素覆盖率及循环接缝诊断。
- [x] GitHub Pages 不配置模型时仍可查看、手动编辑和导入。

## 下一个 P0 — 提升实际 LLM 艺术表现
- [ ] 真实使用不同文本模型（例如 Qwen、Claude、GPT）进行同一组题材的回归测试。
- [ ] 分阶段输出：先轮廓，再色板，再细节，最后动画；避免一次生成数千个像素的困难。
- [ ] 图层局部 Patch DSL，允许只生成一小块而不重写整个场景。
- [ ] 模型生成前后视觉评价与可追溯的差分历史。
- [ ] 减少微小零散块，建立像素簇、体积、轮廓和动画连贯性审美量化规则。
- [ ] 允许人工选择“只重做液体层”“仅微调第 4 帧”等操作。

## P1 — 专业资产工作站
- [ ] 矩形选择、画笔粗细、拾色器、油漆桶、快捷键、网格和 onion skin。
- [ ] 帧差分、首尾重复预览、无缝循环错误高亮。
- [ ] 可重命名作品、整理文件夹、追加调色板和导入 Sprite Sheet。
- [ ] 单层导出、GIF / APNG 导出、云端作品配置。

## P2 — 组装动态像素壁纸
- [ ] Scene DSL：角色、前景、中景、背景、区域光源、镜头时间线。
- [ ] 自然循环粒子与光影合成，风/雨/雪/雾等。
- [ ] 桌面宽屏 16:9 导出及 Lively Wallpaper 页面。
- [ ] 作品展示页关联编辑器资产，创建可公开浏览的 Gallery 项目。
