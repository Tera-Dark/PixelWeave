# PixelWeave · Pixel UI / UX System v0.6

> 范围：作品画廊、分层动画工作站、教学实验室。工程已上线，但真正的跨浏览器美术审查仍需人类查看。

## 设计立场

**精致的像素工具，而不是复古游戏菜单。** UI 从像素画借鉴有限色板、硬朗边界、分明层次和节奏，但不为“8-bit 感”牺牲操作效率和中文可读性。所有 UI 由 CSS 和实际应用数据直接构建，未用图像生成或抠图。

### 关键色彩

- 画布底色 #0d141e；主面板 #172334；次级面板 #1b2b3b。
- 边界 #40556c；主文字 #f2e9da；说明文字 #a0b1c2。
- 交互强调 #e6ad83（铜色）；状态 #9fc9ad（薄荷绿）。

用 8px 为基础的间距、1–2px 硬边和局部内阴影，不随意添加圆角、发光、扫描线或噪声。

## 字体

中文使用 Noto Sans SC / 系统无衬线，正文建议 12–15px；英文标记与紧凑元数据可用 Silkscreen / DM Mono。仅在控件已带文字的情况下用少量像素符号强调，不用抽象图标猜交互意义。

## 页面结构

**Gallery：** 主视觉有大面积呼吸空间，保留当前唯一的 Vermilion Nocturne 药瓶。旧素材已经被用户否决，不能因为旧源码还在就恢复正式展出。

**Studio：** 保留素材库、主画布/时间轴、检查器三段工作流。操作状态明确，播放和绘制独立、导出集中、帧缩略图与实际工作帧同步。公开 Pages 不承载模型 API 密钥。

**Exploded Layers：** 左侧展示按远近顺序斜向展开的真实图层数据；右侧是选中图层的独立观察器，而非插画展示。图层选择从展开板、右侧列表、上一层/下一层共用同一 activeLayer。调节展开距离不会改变源像素。

## 选中图层观察器

- AUTO FIT：计算当前帧非透明像素最小包围盒，再预留 3 像素上下文，使用整数倍率放大。
- FULL CANVAS：完整保留原尺寸坐标，方便判断空间关系。
- 背景可选透明网格或纯深色，不修改图层像素。
- 显示像素数量、bounds、图层可见度与层号。
- 支持导出当前帧当前图层的 **原尺寸透明 PNG**，不是从屏幕截图重采样。
- 选中层可随全局时间轴同步播放。界面中无法修改不属于其图层的数据。
- 输入协议继续保持 layered-v1，焦点视图不生成新的资产副本。

渲染与边界计算见 src/layer-focus.js，样式入口见 src/pixel-ui.css，交互在 src/main.js。

## 响应式与无障碍

大屏：三栏编辑器 + 展开图双列；中屏：素材库移动到上方；手机：单栏，独立观察器先于可横向滚动的长画布。保留原生按钮、label、aria-pressed、focus-visible 与适当尺寸的点击热区。

尊重 prefers-reduced-motion（非必要 CSS 动画禁用）；今后继续补齐动画自动播放的完整辅助技术测试。

## 质量边界

自动测试保证图层结构、bounds、导出原生像素和 UI 控件关联，不保证审美已经达到商业水平。本轮保留药瓶动画，不允许悄悄添加第二件素材。
