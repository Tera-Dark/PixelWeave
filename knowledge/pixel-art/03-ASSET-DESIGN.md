# L1 → L2 · 静态道具到分层动画素材：造型先于细节

**本章核心**：物品不是几个矩形块的堆叠，而是一套“可读的轮廓、逻辑合理的物理结构、统一的材质、明确的视觉焦点”。

## 1. 道具的创作六步

1. **用途定义**：明确玩家/观众应该在第一眼识别“药水”“提灯”“金币”“钥匙”，还是只需感受“神秘、稀有、危险”。
2. **尺寸与投影确定**：16×16 的背包图标、32×32 的精致道具、64×64 的展示插画的设计重点不同。项目中同类物品必须遵守相似的观看距离与透视习惯。
3. **黑白形体**：提取 3–5 个形体关键点；画至少 3 个剪影方案，挑选最具辨识度的一种。
4. **色块与体积**：通常先背景和外轮廓，再基色、主要暗面、亮面。不要过早做微纹理。
5. **材质特征**：玻璃瓶强调边缘折射、内部内容物；提灯金属结构与火光；水晶强调切面而非随意闪光。
6. **可动结构拆分**：先辨别什么应该完全静止，什么会形变，什么独立循环。动画开始前写好层次规划。

**参考案例**：[Slynyrd Pixelblog 24 Items](https://www.slynyrd.com/blog/2019/12/21/pixelblog-24-items)——对 16×16 小道具、类型辨识和适合不同物件的 Idle 动画尤其有价值。

## 2. 实际血瓶结构规范

**建议逻辑画布**：24×24（入门）或 32×32（细节阶段）。仅为练习基准，非绝对最优规格。

画面由以下内容组成：

| 语义对象 | 是否应独立图层 | 是否逐帧变化 | 风险 |
| --- | --- | --- | --- |
| 瓶塞与封蜡 | 是 | 默认静止 | 瓶口位置每帧漂移 |
| 外轮廓与瓶壁 | 是 | 默认静止 | 侧壁粗细忽大忽小 |
| 容器内部透明底色 | 是或合并玻璃层 | 静止 | 变成不透明色块 |
| 药液体积与液面 | 必须独立 | 缓慢变化 | 药液越出瓶壁或体积随意增减 |
| 气泡 | 建议独立 | 稀疏漂浮 | 位置随机闪现、时间节奏不一致 |
| 反射高光 | 独立 | 大部分保持，少量微动 | 玻璃整个轮廓闪烁 |
| 地面阴影 / 光点 | 按场景选择 | 低频变化 | 没接触点或过度抢焦点 |

## 3. 层次要“按语义分”，不是按颜色分

坏做法：红色层、紫色层、白色层、灰色层。好做法：玻璃轮廓、内部药液、气泡、外部光效、瓶塞。因为真实修改通常是“让药液晃得更慢”“移除环境闪光”，而不是“隐藏所有红色”。

层之间应尽量**少重叠、遮挡顺序明确**。透明玻璃层在液体层前还是后，取决于它要表现的玻璃边界和光泽；可以拆为玻璃基底（后）和玻璃高光（前），避免模型猜测所有权。

## 4. 设计稳定锚点与局部重绘边界

每个资产先确定 stableAnchors（逻辑概念，当前 DSL 尚未全部实现）：瓶底接触线、瓶口中心、瓶身最宽两侧、整体重心。LLM 每次修改某一动态图层时，所有稳定锚点的图像坐标保持不变。

建议未来采用 layerPatch 操作而非“重生整张图”：指定 layerId、frameIndices、bbox、allowedSymbols，只允许改变目标范围。这可大幅降低所谓“美术提升”却导致角色/服设漂移的问题。

## 5. 小资产设计通用模板

**Brief**：名称、物体用途、情绪氛围、投影方式、逻辑分辨率、观看背景、受光方向、材质主次。

**Shape Sheet**：3 个单色剪影变体与选择理由。

**Palette Sheet**：轮廓/暗部/基色/亮面/极亮点，用语义而不是单纯编号命名颜色。

**Layer Plan**：按顺序列出每层：id、语义、遮挡、能否动画、稳定锚点。

**Review**：在 1× 原尺寸、灰度、透明棋盘、深浅背景下分别检查。

## 6. 道具动画不应千篇一律

某些游戏道具以浮动展示，某些以落地弹跳，某些仅发亮。液体瓶不一定整瓶浮动；提灯可能只有火焰跳动；金属钥匙不应因为“动画要显眼”而每帧都变形。让动态逻辑服从物理关系和叙事意图。

来源：[Slynyrd Items](https://www.slynyrd.com/blog/2019/12/21/pixelblog-24-items)。

## 7. 交付与质检

输出：一件 32×32 的分层血瓶静态主帧，附上图层职责表、稳定锚点、色板说明。与完成的动画任务独立验收。

**合格条件**：独立隐藏任何动态层都不破坏玻璃主体；所有可动部分有清楚边界；无材质穿帮；层名可让不知情的人直接理解。**失败优先改层次结构与剪影**，不要先开始动画。
