# L3 · 角色动作、布料、自然效果和小型特效

**定位**：能做出不僵硬的角色 Idle / Walk / Run，并让火焰、布料、烟雾等次级物体遵守基本运动逻辑。

## 1. 角色动画的准备

先确定角色视觉规格：视角（正侧背/3⁄4/俯视）、身高（逻辑像素）、头身比、脚底基线、主色板、固定饰物和服装锚点。不要每帧单独重画造型，否则服装和脸的“身份”很容易漂移。

原尺寸静态 Idle 主帧通过后，先做简化人体 Dummy：头/胸/胯/臂/腿几个单色块。**先让 Dummy 的运动正确，再着色加配饰**。

来源：[Slynyrd Motion Cycles](https://www.slynyrd.com/blog/2020/1/23/pixelblog-25-motion-cycles)、[Saint11 教程合集](https://saint11.org/blog/pixel-art-tutorials/)。

## 2. Idle 动画的三个层次

1. 重心/胸腔：呼吸带来极微小的轮廓变化或身体上下位移。
2. 次级运动：头发、衣角、绳带/饰品有延迟响应，频率不必一致。
3. 表演：眼神、视线、眨眼，节奏疏密可不规则，但需可控循环。

低分辨率角色未必适合每帧都全身上下浮动。许多令人舒适的 Idle 只有 2–4 帧细微变化。观众应感到“在呼吸”，不是“角色一直在抽搐”。

## 3. Walk 与 Run

标准步行动画可按以下关键姿态规划：接触 Contact → 下沉 Down → 越过 Passing → 上升 Up → 反脚接触。左右循环在对称角色上可以镜像，但武器、衣服、头发不对称的角色需手工校正。

重要问题：
- 脚接地时不能大范围滑动（foot sliding）。
- 躯干、头、肩、胯之间要保持有意义的体积与受力关系。
- 手臂自然摆动方向往往与同侧腿不同步。
- 动作进入/离开场景的基线和碰撞盒要稳定。
- Run 的空中相、接地时间和躯干前倾通常比 Walk 更明显。

参考：[Slynyrd Motion Cycles](https://www.slynyrd.com/blog/2020/1/23/pixelblog-25-motion-cycles) 与 [Pixelblog 8](https://www.slynyrd.com/blog/2018/8/19/pixelblog-8-intro-to-animation)。

## 4. 材质和次级动画分开

- 头发、飘带：根部与头部/身体绑定，末端延后响应。
- 布料/旗帜：褶皱方向受风向、重力和固定点影响；不要让整个形状每帧随机改变。
- 火焰：固定基部、上方变化较大，内核明亮、边缘暗，变化有方向偏好。
- 烟雾：体积逐渐上升、松散和淡出，而非突然出现大量碎点。
- 水花：依碰撞/冲击方向展开、破碎、落下；短暂快速而非长期匀速漂浮。
- 魔法光：有主发光面与辅助小粒子；亮点运动应服从主光节奏。

参考：[Saint11 火焰/烟雾/布料/特效专题](https://saint11.org/blog/pixel-art-tutorials/)。

## 5. 动画分层的规范化命名

建议 root/body/face/hair/cloth/equipment/fx/shadow，或者语义相近的名称；每层提供稳定锚点 parentAnchor，未来支持关联层变换。禁止用 color_1、red_layer 之类无含义的名称作为常规做法。

## 6. 练习顺序

A. 16×16 火焰 6 帧：脚底固定、顶部不同形状。  
B. 32×32 布旗 8 帧：旗杆固定，褶皱顺风移动。  
C. 24×32 Dummy Idle 4 帧：脚下基线固定。  
D. 24×32 Dummy Walk 6–8 帧：接触、下沉、经过、上升。  
E. 在 D 上添加服装、头发与次级运动。

**通过条件**：动态的主动作有表现力；静态结构不漂移；低分辨率不会因为服饰细节而牺牲动作清晰性。无法通过时返工 Dummy 的关键姿态，而非继续叠加发丝、粒子。
