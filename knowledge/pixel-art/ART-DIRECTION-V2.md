# PixelWeave · Fantasy Sprite Art Direction v2

> 2026-10-24 · 32×32 原创像素资产美术迭代说明。**代码生成美术研究，不是 LLM 生成结果，也未经独立资深像素画师审定。**

## 为什么推倒前一批案例？

旧案例虽然满足帧数与图层结构，但大量依赖矩形叠加、居中对称、直接填充纯色，并且动态只有少量离散像素。特别是 Ember Flame，旧版黑色横条底座 + 正三角红色火舌是“演示数据”，不是值得模型模仿的高品质美术案例。

### 新艺术基调

**Nocturne Atelier / 夜色手工像素工坊**：统一深墨蓝紫轮廓、暖金属/乳白高光、深红与冷青紫互为补色，采用 32×32 整数网格、适度不对称的硬质轮廓、明确的材质切面、微量高光。全画面遵守阅读层级：剪影 → 结构大色块 → 材质体积 → 一两处最亮的叙事焦点。

禁止“为了精致而撒点”或“让每一层都不停闪动”。参考方向：Slynyrd 在 Pixelblog Intro to Animation 强调清晰簇与稳定关键帧；Saint11 的火焰教程展示火舌独立节奏。它们是原则参考，不复制外部精灵资产与教程图片。

## 美术操作优先级

1. **剪影（最重要）**：失去细节时仍需识别道具。图标四角尽量留下负空间。
2. **材质**：每种材质的高光必须形状不同：玻璃沿壁窄线，金属沿切角硬反差，矿晶以面为单位分组。
3. **像素簇**：优先连续暗部/受光面，1px 散点须有物理职责（泡泡、火星、镜面闪烁）。
4. **反差与饱和**：冷暖互补服务焦点；即使色数 16+ 也不意味着把全部颜色用满。
5. **动画身份稳定**：停止、关闭动态层时必须仍然是合理静态资产。
6. **制作真实循环**：相邻帧与末尾到首帧都检查，运动幅度遵循材质与语义；火焰可以比坚固金属框架动得多。

- 独立素材：knowledge/pixel-art/examples/reference/*.layered.json
- 精灵数据生成代码：tools/build-reference-assets.mjs 的 buildReferenceLibrary()。
- [六件作品的 SVG 静帧联系表](../visuals/studies-v2-contact.svg)
- 网页工作站将新版作为 Gallery 首选；旧版通过“查看旧版演示”保留为历史对比。
- 每件为 32×32、8 帧，多语义层可选、可人工修改。所有图层均经过 schema 自动校验。
- 视觉对比：真人观看 1× + 8×、逐帧与真实帧率、透明底与深色背景、动态关闭重看主体。

## 还没解决的核心问题

高品质像素动画不仅是“程序能运行”和“图标更像样”。**现在仍未进行外部画师打分和完整角色/场景的视觉审阅。** 下一阶段必须对单帧美商、材质表现和运动的专业性进行盲评；不能把软件测试等同艺术测试。六件作品的概念更统一，但不是 AAA 级像素美术资产。
