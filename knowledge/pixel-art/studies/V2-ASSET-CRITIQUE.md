# PixelWeave V2 六件资产：美术复核与重制命题

记录时间：2026-10-24。用户自评当前图库 **6.4/10**，本文件以此作为设计复盘起点，不冒充专业评审结论。

## 复盘统一准则

每个项目先写出 **“身份 → 体积 → 光 → 动作”** 四层判断。不要提出“换成 64×64、给更多光斑、加两个粒子”这种能快速增加复杂度但不提高设计的建议。

### 1. Gilded Reliquary Key
- 现状：圆形钥匙柄 + 蓝宝石 + 长齿，漂亮但过于通用的 JRPG 素材。
- P0：确认来自哪里？例如失火钟楼的最后一把黄铜钥匙。设计形体 A（断开的表盘齿）/B（扁柄片钥）/C（带锁芯回勾），必须有结构原因。
- P1：把金属高光集中在转折/磨损部位；过大宝石可影响识别，应控制焦点主次。
- Animation：不应一直有闪光；只需一次极缓慢反光运动，甚至完全静止亦可。

### 2. Vermilion Nocturne
- 现状：玻璃受光清晰，但对称外形与大面积粉红液体像普通游戏图标。
- P0：三轮廓（底宽沉积 / 窄颈轻薄 / 带金属修补片的不规则手工玻璃）。
- P1：在瓶颈、底腹和侧壁分别表现不同的玻璃厚度；药液亮区和玻璃表面反光不能混成单个色块。
- Motion：液面、内壁反射与气泡三者不必同频运动；每一帧不能令液体穿过瓶壁。
- 验收：隐藏气泡、火花仍然是精致静态玻璃工艺品。

### 3. The Lamplighter's Oath
- 现状：装饰完整，但栅格与大灯冠挡住内部火光，物体空间感仍扁平。
- P0：强化提手、灯罩、玻璃腔、支架纵深和不对称维修痕迹。
- P1：灯芯位置锁定，火焰运动与玻璃内侧的投影/反射相关；金属高光沿实体拐角移动。
- 动效审核：用两个层组合观察是否像真实物体，而不是灯框 + 红色条纹 GIF。

### 4. Vesper Geode
- 现状：紫晶轮廓清楚，但各面过于平均加亮，缺少主切面。
- P0：一枚折断主晶决定方向，其余次晶只支持它，不争亮度。
- P1：固定 3 级大明暗面，极亮点只位于其中一个受光切面，避免所有晶尖闪光。
- 动效：晶体本体一般无需弹跳，可让反光缓慢掠过自然断面。

### 5. Ashen Standard
- 现状：材质/颜色完整但旗布像一块坚硬垂直矩形。
- P0：画 3 个风方向草稿；旗角必须有不同曲率。
- P1：将布根和末端的变形幅度分层，让中间折角存在受力逻辑。
- 动效：旗杆固定，根部几乎不动，末端 1–3 像素不同步响应。当前“褶皱 == 像素移动”需要改成成片折面变化。

### 6. Cinderwake
- 现状：红—黄—白层次虽清晰，但轮廓近似经典 RPG 对称火焰符号，根部缺少空气透入的空间。
- P0：先研究燃烧物：旧灯芯火、薪炭火、灵火是三种完全不同的形体。
- P1：主火舌、逆向副火舌、炭火热亮纹理具有独立时间常数。
- 动效：增加具方向意义的极值帧，而不是 8 帧平均抖动；火焰边界不必每帧全部一起变。
- 验收：8 帧正常速度和逐帧观看都不呈现随机电视雪花；火焰前沿没有明显周期“折断”。

## 下一轮实验必须保留对照

只挑**药瓶、提灯**做首轮（涵盖透明、金属、暖光、动态）。按 G0–G7 记录候选，保留 V2 作为基线。不直接覆盖现有 6 件作品。

**候选交付：**
- 三种可比较的黑白剪影；
- 一张静帧色板与材质设计表；
- 主体/效果图层分离的工程 JSON；
- 原尺寸/放大/深浅背景/目标场景四类预览；
- 正常速度与慢速动画；
- 人工书面评分及允许修订的 bbox；
- 若完成评审，才进入精选画廊。

**这份评估仍是分析，不是已经存在的新作品。** 当前 V2 资产不会被静默替换。
