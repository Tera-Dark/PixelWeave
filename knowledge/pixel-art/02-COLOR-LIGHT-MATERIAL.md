# L1 · 色板、光影和材质设计

**前置**：[01 基础语法](01-FOUNDATIONS.md)。**结业**：用有限颜色把玻璃、金属、液体区别开。

## 1. 色板不是“颜色越丰富越精致”

建立功能性色板：轮廓暗色 / 受光暗面 / 主基色 / 受光亮面 / 极亮点 / 材质专属色。初学练习 4–8 个实际颜色足够；复杂画面可拓展为 12、16、32 色或更多，取决于风格，不设统一上限。

**色板渐变 Color Ramp**：一个物体从暗部到亮部的若干颜色应形成明度与色相的合理路径；不要只把 RGB 三通道一起加亮。Hue Shift 可让冷暖、光源、情绪更丰富，但也不是强制配方。

参考：[Slynyrd 色板指南](https://www.slynyrd.com/blog/2018/1/10/pixelblog-1-color-palettes)；[Lospec Palette List](https://lospec.com/palette-list/)。

## 2. 先明度，再色相，最后饱和度

一套稳定的工作顺序：
1. 选定画面主光方向与背景明度。
2. 在灰度图上建立清晰的亮/中/暗三大面。
3. 以色相和饱和度区别温度、材质、情绪。
4. 用非常少的极亮点建立画面注意力。
5. 在实际展示背景上检查透明资产；不要只用棋盘格看图。

**禁止把阴影写成“整个物体底部一律加黑”。** 阴影应解释几何形体、接触关系、投影与环境光。多光源可存在，但需要主次关系。

参考：[Slynyrd Light and Shadow](https://www.slynyrd.com/blog/2018/6/15/pixelblog-6-light-and-shadow)；[Derek Yu Pixel Art Basics](https://derekyu.com/makegames/pixelart.html)。

## 3. AA 与 Dithering 的使用边界

AA：用精心选择的中间色柔化局部曲线。低分辨率、硬朗复古设计可无需 AA。处理轮廓时先确定线条节奏，再决定要不要 AA。

Dithering：用特定离散图案在有限调色板下模拟过渡、颗粒或材质。适合硬件风格和有明确媒介感的作品；若对 16×16 小瓶全表面撒棋盘噪点，反而会毁掉像素簇。

Ditherpunk 是一个可以选择的特定艺术方向（高对比、抖动图案和复古视觉表达），**不是像素动画的默认风格**。风格标签必须跟构图、美术角色一致。

阅读：[Pixel Joint 对 AA/抖动/噪点的讨论](https://pixeljoint.com/forum/forum_posts.asp?TID=11299)；[Slynyrd Texture](https://www.slynyrd.com/blog/2018/2/15/pixelblog-2-texture)。

## 4. 四种材质的“识别特征”

### 玻璃 Glass

玻璃由外缘、局部折射/透射、高反差窄反光以及“能看到瓶内物体”共同表达。不要把全部瓶壁涂成不透明的白框；瓶壁厚度在转角处可用像素簇强调。试验时先建立稳定玻璃层，动态液体另立一层。

### 液体 Liquid

液面与容器壁有联系；液体体积受容器形状约束。主色块连续，液面高光可断续而非每像素均闪。气泡频率和尺寸应与液体环境一致。参考 [Slynyrd 水体动画](https://www.slynyrd.com/blog/2018/10/12/pixelblog-10-water-in-motion)。

### 金属 Metal

需要相对硬、窄、高反差的反光，亮暗面突变比木头/布料更鲜明。金属表现重点是切面结构及映照光源，不是均匀铺大量黄点。

### 木材/石材/织物

木头纹理顺结构，石材依大块断面与碎裂，布料靠褶皱方向与厚度变化。纹理分布要服务受光、形体和视觉重点。**纹理要从抽象形状构成，而不是噪点铺满**。

阅读：[Slynyrd Texture](https://www.slynyrd.com/blog/2018/2/15/pixelblog-2-texture)；[Saint11 主题教程索引](https://saint11.org/blog/pixel-art-tutorials/)。

## 5. Texture：重复不等于机械平铺

训练时画出 2–4 种典型微结构：石头凹口、树皮竖纹、砖缝、金属反光。但要调节疏密、方向、聚散，使焦点区域更明确。材质信息应服从物体大形体。可以用程序化纹理生成初稿，**最终需按像素簇逻辑清理**。

## 6. 光照一体化检查清单

- 主光位置明确；材质反光与该光源相符。
- 投影方向与接触位置匹配；没有无故漂浮。
- 角色/道具/背景色板共享环境色的逻辑。
- 高光面积远小于主体面积，除非有意设计强发光物。
- 发光物是“光源 + 被照亮的邻近表面”，不是只有自身发白。
- 暗部仍保留关键结构，不是一团纯黑无信息。

## 7. L1 结业：三件静态资产

**24×24 或 32×32，建议 8–12 个实际颜色**：
- 玻璃血瓶：表现瓶壁、内部药液与瓶塞。
- 黄铜提灯：表现金属反光和玻璃罩。
- 裂纹魔晶：表现切面、半透明层次及主发光面。

提供三件资产的：彩色版、黑白版、灰度版、调色板表、光源示意。人工能在原尺寸看出三种材质差异才通过。

**模型分工**：先定 palette 与光向，再分玻璃/主体/高光图层；高光层不得推翻经过审核的剪影。失败时返回具体“材质识别失败”的区域，而不是要求“整体更精美”。
