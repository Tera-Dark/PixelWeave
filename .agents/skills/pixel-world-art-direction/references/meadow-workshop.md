# Original cozy pixel-world direction

Use this reference when the requested work needs a concrete warm countryside art direction. It translates studied design principles into a new visual vocabulary; it is not a replica or an asset pack.

## Visual grammar

- Create a named world and its own narrative. PixelWeave's Meadow Workshop uses botanical craft tools, a small observatory, invented flowers and terraced paths. Do not use the source game's title, characters, landmarks, interface arrangement, recognizable assets or extracted textures.
- Define a small, hand-picked palette by function. Example starting ramps: ink `#553e32`, bark `#815136`, wood `#c28b55`, honey `#e4b870`, paper `#fff1d0`, leaf `#63885e`, sky `#b8dcdd`, berry `#c46b55`. Tune against artwork and text contrast, not exact game colors.
- Use medium-value separation for tiny objects; give 16–32 px sprites one dominant silhouette with a small number of coherent highlight and shadow clusters. Keep highlights toward a consistent light source and avoid random texture.
- Tiles or sprites may use different native resolutions; decide according to subject detail. Favor integer enlargement and crisp edges. Avoid placing a detailed pattern beneath an editing canvas.
- Frame components with independently authored stepped edges and subtle material cues. Controls must remain distinct from each other, and remain legible in default, hover, focus, selected, disabled and error states. Body copy need not use a pixel font.
- Animate a small number of independently authored elements such as a flag, drifting pollen, or watering can shimmer. Loops should have deliberate timing, stop offscreen and respect reduced motion.
